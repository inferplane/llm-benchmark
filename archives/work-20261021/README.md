디스크 정리를 위해 `.work`의 미커밋 결과와 재시도 기준 자료를 보존한
**실패·미검증 결과를 포함하는 원본 아카이브**다. 서비스의 승인된 예제나 새로운
벤치마크 집계 결과로 사용하지 않는다. 공개 백업은 2026-10-21 저장소 소유자가
승인했다.

`source-manifest.json`에는 각 원본의 경로, 크기, SHA-256과 복제 저장소의 변경
상태를 기록했다. 압축본 내부의 `BACKUP-MANIFEST.json`도 같은 내용이다.
`SHA256SUMS`는 압축본과 외부 파일 목록의 체크섬이다.

파일 바이트는 원본 그대로 보존했다. 과거 `STATE.md` 및 백업 생성 당시 메타데이터의
비공개·실행 중 지시는 역사적 기록이며, 현재 실행할 명령이나 현재 공개 상태를
나타내지 않는다. HTML 결과에는 실행 오류나 요구사항 미충족 내용이 있을 수 있다.

복제 저장소의 기준 커밋과 원본 자료를 함께 사용하면 작업 상태를 재구성할 수 있다.
압축본을 서비스의 `docs/` 디렉터리에 풀거나 승인된 갤러리에 연결하지 않는다.

## 검증 및 복구

아카이브 디렉터리에서 실행한다.

```sh
sha256sum -c SHA256SUMS
tar -tzf work-uncommitted.tar.gz
```

원본 확인만 필요하면 압축을 **비어 있는 별도 디렉터리**에 푼다. 경로는 `.work/`로
시작하며, 압축본에는 Git 메타데이터나 실행 환경이 없다.

```sh
mkdir restored-work
tar -xzf work-uncommitted.tar.gz -C restored-work
```

복제 저장소 전체를 복구하려면 이 저장소의 별도 클론을 만들고
`source-manifest.json`의 `publisher_head` 커밋을 체크아웃한 뒤,
추출한 `.work/model-pages-publisher/`의 파일을 그 클론에 덮어쓴다.
재시도 기준 자료 두 디렉터리는 추출된 파일만으로 복구된다.
Git LFS로 관리되는 과거 결과가 필요하면 클론에서 해당 LFS 객체도 내려받는다.

공개 전 자격증명 패턴 검사에서 일치 항목이 없었으며, 562개 파일 모두 현재 원본과
압축본의 해시가 일치하는지 확인했다. 이는 생성 결과물의 기능·품질 승인과는 별개다.
