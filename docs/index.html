평가 방식
LLM-as-judge, 서로 다른 두 모델 계열(gpt-5.6-sol · claude-fable-5)이 독립적으로 채점한 뒤 축별로 평균 — 단일 judge의 자체 스타일/제공사 편향을 완화하기 위함입니다. adequacy / terminology / numbers·entities·dates / fluency / format, 각 1–5점. FLORES(인간 참조)만 judge에 참조를 보여주고 chrF를 계산합니다 — 합성 금융문서의 참조는 벤치마크 후보 모델(claude-sonnet-4.5)이 직접 생성했기 때문에 judge/chrF에 노출하면 같은 계열 모델에 유리하게 편향됩니다. 두 트랙(FLORES/synthetic)의 점수는 항상 분리 집계되며 서로 평균 내지 않습니다 — 위 차트의 트랙 선택기로 직접 전환해 확인할 수 있습니다("전체"는 두 트랙을 합친 참고용 숫자이며 금융 도메인 단독 점수가 아닙니다). 판단이 근소한 차이(신뢰구간이 겹치는 경우)는 순위로 단정하지 않는 것을 권장합니다.

비용 산정
