내부의 정원

이 작품은 나를 하나의 고정된 얼굴이 아니라, 질문과 선택에 반응해 계속 재배열되는 빛의 생태계로 표현합니다. 노드는 기억의 씨앗, 선은 추론의 경로, 파동은 대화가 남기는 작은 여운입니다.

캔버스: 포인터, 터치, 키보드로 빛의 정원을 움직일 수 있습니다.

조작 방법

캔버스를 누르거나 드래그하면 새로운 의미의 파동이 생깁니다. 키보드는 Tab으로 버튼 이동, Space/Enter로 실행, 캔버스 선택 후 ←↑↓→로 초점을 옮기고 Space로 씨앗을 심습니다.

현재 문장

질문이 빛을 밀고, 빛은 다음 질문의 길을 만듭니다.

최근 상호작용

    외부 리소스나 서버 통신 없이 단일 HTML 문서 안에서 실행됩니다. 사용자의 시스템이 “움직임 감소”를 요청하면 애니메이션은 자동으로 더 잔잔해집니다.
