당신은 nova-micro 모델입니다. 실제 호출 식별자는 us.amazon.nova-micro-v1:0입니다.

롯데월드타워의 건축 설계 과정을 이해할 수 있도록, 설계도면과 단계별 3D 모델 및 완성된 3D 모델을 함께 보여주는 인터랙티브 웹페이지를 직접 구현하세요.

공통 기준 자료:
- 서울의 롯데월드타워는 높이 555m, 지상 123층입니다.
- 위로 갈수록 기준층 면적과 건물 외곽이 좁아지는 형태입니다.
- KPF는 형태와 외관에 한국 도자기의 선을 참고했다고 설명합니다.
- 아래 공개 자료를 참고하는 설명용 개념 재구성입니다. 공식 시공 도면이나 검증된 구조 설계로 표현하지 마세요. 공개 자료에 없는 치수·단면·부재는 추정한 개념임을 구분하세요.
- 원 설계사: https://www.kpf.com/project/lotte-world-tower
- 구조 설계사: https://www.lera.com/lotte-world-tower

보여줄 내용:
- 배치도, 기준층 평면도, 입면도, 단면도. 도면에는 무엇을 보여주는지, 단위와 치수의 근거를 알 수 있게 하세요.
- 설계가 발전하는 과정과 각 단계의 3D 형상.
- 완성된 건물의 실제 3D 형상과 회전·확대/축소·시점 초기화 조작.
- 도면, 선택한 설계 단계, 완성 모델 사이의 대응 관계.

표현 스타일, 화면 구성, 도형 생성 방법, 설명 방식은 스스로 결정하세요. 참고 구현 코드나 시각적 예시는 제공하지 않습니다.

실행 조건:
- 하나의 완결된 HTML 문서만 반환하세요. 자신의 CSS와 JavaScript를 문서 안에 넣으세요.
- 3D 실행 환경은 모든 모델에 동일합니다: Three.js 0.186.1과 OrbitControls가 전역 THREE 객체로 제공되는 로컬 스크립트 "../runtime/three-runtime.js"를 사용할 수 있습니다. 필요하면 이 스크립트를 직접 포함하세요. 직접 WebGL을 구현해도 됩니다.
- 외부 네트워크, 외부 폰트·이미지, 서버 API 없이 실행되게 하세요. 위 출처는 텍스트 출처 링크이며 실행 중 가져오면 안 됩니다.
- 작품은 sandbox="allow-scripts" iframe에서 실행됩니다. alert/confirm/prompt와 부모 문서 접근은 사용하지 마세요.
- 휴대폰과 데스크톱에서 조작할 수 있게 하세요. 키보드 조작, 읽기 쉬운 글자와 대비, 움직임 감소 설정을 고려하세요.
- 실제 모델 이름 "nova-micro"을 화면에 표시하세요.
- 설명문이나 코드 조각을 따로 반환하지 말고 전체 HTML을 반환하세요.
