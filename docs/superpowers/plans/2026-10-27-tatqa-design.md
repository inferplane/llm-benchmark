# TAT-QA 200-question benchmark

Add TAT-QA alongside the existing audited FinQA benchmark. Use the official released test gold at NExTplusplus/TAT-QA revision 870accc41953dcde885aabeb963d94aabdc0fbc3, CC BY 4.0, ACL 2021. Freeze 200 distinct questions from 200 distinct table/document contexts using seed 20261027, preserving approximate test answer-type proportions (span 86, arithmetic 84, multi-span 25, count 5). Selection is deterministic and never examines model answers. This is a published official-rule subset, not the official full leaderboard.

Candidate inputs contain only table, paragraphs and question. Gold answer/type/scale/evidence/derivation remain offline. Ask for JSON {"answer": scalar or list, "scale": ""|"thousand"|"million"|"billion"|"percent"}. Preserve official numeric scaling and multi-span EM/F1 behavior. Only an outer JSON fence may be stripped. Invalid, failed, missing and truncated responses score zero and remain in the denominator; raw responses are retained. No LLM judge or answer repair.

Start with all enabled generative API models in config.toml without base_url (35 at design time), including gpt-6.1-terra. Self-hosted GPUs need a separate execution cohort; disclose exclusions. Existing provider reasoning and temperature contracts remain unchanged. Freeze complete roster, source/data/prompt/evaluator/runner hashes, generation and concurrency settings before the first request. Append-only successful-only caches, latest row deduplication, immutable resume contract. Costs use existing model-level reporting path and configured historical rates, withholding expired rates; per-answer-type metrics have quality/counts only.

New CLI: uv run python -m bench.tatqa prepare|run|report|--selfcheck. New output: results/tatqa/<run-id>/ and docs/tatqa-results/{index.json,<run-id>.json}. Report schema: run_id, scenario="tatqa", dataset={questions,documents,answer_types,source_url,source_revision,source_sha256,dataset_sha256,seed,split}, protocol={description,official_evaluator_revision,limitations}, models=[{name,provider,metrics={total,exact_match,f1,correct,response_coverage,scored,invalid,request_failures,missing,truncated,estimated_cost_usd,estimated_cost_per_question_usd,cost_unavailable_reason,latency_p50_s,latency_p95_s,tokens_in,tokens_out},by_answer_type={type:{total,exact_match,f1,correct}},...}], excluded_models, samples=[{id,question,answer_type,gold_answer,gold_scale,predictions:[{model,answer,scale,exact_match,f1,status}]}]. Percent metrics stored 0..1. No invented/stub results for unavailable models.

New dashboard docs/tatqa.html + tatqa.js uses existing stylesheet, navigation, plain JS and no-store fetch. Display 200 questions, 200 contexts, EM/F1, coverage/failures, type breakdown, costs/latency and source/protocol limitations. Keep audited FinQA intact; navigation clearly distinguishes both. Render untrusted strings as text.

Verification: scorer hand-computed numeric-scale/span/multispan/missing/error cases, parity with pinned official evaluator; dataset stability and prompt leakage checks; frozen run/resume and report full-denominator checks; existing report selfcheck. Code review and mandatory content-review score >=85 precede deployment. User already authorized deployment; commit, push, merge and verify GitHub Pages with ordinary Git report JSON, preserving existing artifacts.
