01 · MODEL COMPARISON

정답·시간·비용 한눈에 비교

문서 이해·계산과 함께 지정 JSON 형식 준수까지 평가한 점수입니다. 정답이 포함되어도 설명이 섞인 응답은 형식 오류로 0점입니다.

EM은 정규화된 정답과 완전히 일치한 비율, F1은 부분 일치를 반영한 공식 평가 점수입니다. 둘 다 전체 200문항을 분모로 하며, 실패·누락·형식 오류·출력 잘림은 0점입니다. 한 문항은 EM 0.5%p에 해당하며, 근소한 차이만으로 우열을 단정할 수는 없습니다.

모델 전체 200문항 기준 비교. EM과 F1은 형식 준수를 포함하며 높을수록 좋습니다.

03 · ANSWER EXPLORER

같은 질문에 어떻게 답했나요?

공식 정답과 두 모델의 제출 답을 나란히 확인하세요. 정답과 단위는 평가할 때만 사용하며 모델 입력에는 포함하지 않습니다.

응답 커버리지·실패·누락·모델 전체 비용

응답 커버리지 = (채점 가능 + 형식 오류) / 전체 문항으로, 잘리지 않은 응답의 비율이며 정답률이 아닙니다. 요청 실패·누락·출력 잘림은 커버리지에서 제외합니다. 누락은 아직 실행되지 않았거나 기록이 없는 문항, 요청 실패는 API 호출 오류, 형식 오류는 채점 가능한 답을 파싱하지 못한 응답입니다.

모델채점 가능 / 전체형식 오류요청 실패누락출력 잘림P95 응답 초전체 비용 USD · 추정입력 / 출력 토큰

P95는 응답의 95%가 이 시간 안에 도착했다는 뜻입니다. 응답 시간과 토큰은 실제 기록이 있는 요청 기준이며, 누락된 요청의 비용을 0달러로 가정하지 않습니다. —는 값이 없다는 뜻으로 0과 구분합니다.

표와 점수는 문항별 마지막 기록 기준입니다. 재시도 이전의 실패도 원본 실행 기록 ↗에 보존합니다. 재시도·실패 호출 비용은 추정치에서 제외합니다.

공식 test에서 고정한 200문항

seed 20261027로 서로 다른 표·본문 묶음에서 질문을 하나씩 선정합니다. 단일 답 추출 86개, 계산 84개, 여러 답 추출 25개, 개수 세기 5개입니다. 모델 답변을 보고 질문을 고르지 않습니다.

200개의 표·본문 맥락은 원본 기업 보고서 200개가 서로 독립이라는 뜻이 아닙니다.

공식 평가 규칙으로 EM·F1 채점

표·본문·질문만 입력하고, 답과 scale을 JSON으로 받습니다. 숫자와 단위 환산, 다중 답 비교에는 고정한 TAT-QA 공식 평가기를 사용합니다. 바깥 JSON 코드블록만 제거하며 답을 자동 수정하거나 LLM으로 재채점하지 않습니다.

문서 이해·계산과 지정 JSON 형식 준수를 함께 평가합니다. JSON 앞뒤에 설명이 섞이면 정답이 포함되어도 형식 오류로 0점입니다. 이런 응답에서 정답만 추출해 다시 채점하지 않습니다.

결과의 적용 범위

공개된 test 정답을 사용하므로 학습 데이터 포함 가능성을 배제할 수 없습니다. 공식 전체 리더보드, 기존 FinQA 감사 20문항, 실제 금융 업무 전체와 점수를 직접 등치하지 마세요. 회사 문서의 검색·OCR 성능과 업무 판단의 안전성은 별도 검증이 필요합니다.
