# 감사된 금융 QA

기존 FinQA 실행값 일치율은 백분율의 소수 비율·퍼센트 표현 차이와 원본 주석 오류를
추론 실패와 구분하지 못했다. 이 시나리오는 새 문항의 근거·단위를 호출 전에
검토하고, 모델이 선언한 결과 단위에 따라서만 환산한다. **공식 FinQA 점수가 아니다.**

## 재현

Python 3.12와 저장소의 `uv` 환경을 사용한다.

```bash
uv run python -m scenarios.finqa_audited.prepare --source /path/to/pinned/dev.json
uv run python -m bench.finqa_audited selfcheck
uv run python -m scenarios.finqa_audited.legacy_audit
# 데이터/규약 리뷰 후, 첫 모델 호출 전에 한 번 생성:
uv run python -m bench.finqa_audited freeze
uv run python -m bench.finqa_audited run --models gpt-5.5 --run-id finqa-audited-20260919-gpt-5.5
# 전체 로스터의 모델마다 같은 규약으로 수집한 뒤:
uv run python -m bench.finqa_audited report --run-id finqa-audited-20260919
```

소스는 `czyssrs/FinQA` revision `0f16e2867befa6840783e58be38c9efb9229d742`의
`dataset/dev.json`이다. SHA-256은
`a847fb7e0d61a3125a1e2909852df6b89f1ee64d2c5ff1bf689e332214deee51`.
MIT 라이선스는 `../finqa/LICENSE.FinQA`에 보존한다.

## 선정·감사

`selection-audit.json`에는 기존 20개 문항 ID를 제외하고 source ID로 정렬,
seed `20260919`로 셔플한 후보 순서와 모든 검토·제외 이유가 있다.
앞에서부터 질문의 시점·대상·단위·정답 근거를 확인해 20문항을 선택한다.
원래 질문·표·본문은 수정하지 않고, 모호하거나 주석이 잘못된 문항을 제외한다.
같은 문서의 다른 질문은 포함될 수 있다. 모델 학습에서 보지 않은 자료라는 뜻은 아니다.

각 정답은 원문 숫자로 직접 계산한 유리수로 기록하고 공식 계산식과 대조했다.
별도 AI 리뷰가 전체 문맥과 수작업 계산을 재검토한다. 이 검토는 회계 전문가의
인증이나 원본 PDF 전체의 OCR 검수가 아니다. 답에 사용하지 않는 셀의 OCR 오류,
근사치로 주어진 입력, 사전 선별에 따른 난이도 변화 등의 한계가 있다.

`freeze.json`은 첫 호출 전에 데이터·프롬프트·단위표·평가기·공유 실행기의
해시와 시각을 고정한다. 각 모델 manifest에 전체 freeze를 저장하고 보고서
구성 시 일치 여부와 실행 순서를 검사한다. 규약을 바꾸고 같은 실행을 재사용하지 않는다.

## 점수

계산식의 최종 결과에 선언된 단위를 적용한다. ratio/percent는 같은 비율 차원,
percentage_point는 비율의 상대 변화와 다른 차원이다. 달러 배율과 개수 배율도
각 차원 내에서만 환산한다. 누락 단위는 추정하지 않는다.

사칙연산·표 집계에는 유리수를 사용하고, 지수 연산은 기존 제한된 인터프리터의
부동소수 계산을 유지한다. 문항의 기준 단위로 환산한 뒤 소수점 5자리로 한 번
반올림한다(ties to even). 이 정밀도는 표시된 입력값으로 계산한 결과의 비교 규약이며,
원문 근사치 이상의 실세계 정확도를 뜻하지 않는다.
숫자 지수는 ±308, 유리수의 분자·분모는 4096비트로 제한한다.
범위를 넘는 연산은 큰 결과를 생성하기 전에 거부하고, JSON에 저장할 수 없는
무한대 결과도 오류로 분류한다.

주 점수 분모는 예정된 20문항 전체다. 형식 오류·단위 오류·통신 실패·누락을
제외하지 않는다. 원래 형식의 정답 여부, 계산식 실행 여부, 선언 단위 유효 여부,
요청 단위·배율 준수 여부는 별도 기록한다. 요청 단위가 생략된 질문은
문서에 명시된 배율을 기준으로 삼는다.

Wilson 95% 구간은 표본의 이항 정답률에 대한 참고치다. 문서 간 의존성,
선별 편향, 제공자 설정 변화, 반복 실행 변동은 포괄하지 않는다.
20문항은 한 문항이 5%p이며, 28개 모델 탐색 비교를 확정적 전체 순위로 해석하지 않는다.

## 실행 조건과 비용

기존 28개 생성 모델, 추론 설정, 컨텍스트, 출력 상한4096, 동시성을 유지한다.
프롬프트와 문항은 모든 모델에 같지만 제공자의 기본 추론량이 같다고 가정하지 않는다.
Mantle 요청 JSON과 Bedrock/vLLM SDK 호출 인자를 모의 전송으로 검사하고, 제공되는 응답 모델명·종료 사유·
reasoning 토큰을 저장한다. 생략된 설정과 제공되지 않는 메타데이터는 미확인으로 표시한다.
이 검사는 SDK 이후 제공자 수락 여부를 대신하지 않는다. 실제 호출 결과에서
요청 성공·종료 상태를 별도로 확인한다. GPU 서버 이미지와 컨텍스트도 규약에 고정한다.

비용은 `config.toml` 단가로 계산한 성공 응답·GPU 응답 구간의 추정치다.
준비·다운로드·유휴·실패·재시도 전체의 청구 금액이 아니다.
만료된 단가는 표시하지 않으며, 2026-09-19 공식 가격 페이지 확인만으로
동적 가격 자리표시자의 모든 숫자를 재검증했다고 주장하지 않는다.
모델별 총비용·문항당 비용·지연시간만 제시하고 문항 하위집합 비용을 계산하지 않는다.
