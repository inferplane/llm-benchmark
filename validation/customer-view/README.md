# 고객용 결과 페이지

번역 페이지는 언어쌍별 품질 표와 비용 대비 품질 차트를 먼저 보여주고, 이어서
워크로드 후보, 한 건 응답 시간, 예상 처리량 비용, 두 모델의 실제 결과물을 비교한다.
측정값·데이터·채점기·가격 설정은 수정하지 않는다.
오류 및 측정 조건, 상세 품질 지표, 과거 이력은 접힌 상세 영역에 보존한다.

## 표시 및 후보 선정

- 언어쌍 표는 선택한 결과, 최신 통합 결과, 기본 표시로 지정된 결과의 언어쌍을 모델
  이름 기준으로 합쳐 KO→X, EN→X, X→KO, X→EN을 한 화면에서 보여준다. 같은 모델·언어쌍은
  먼저 나온 결과를 쓰고 덮어쓰지 않으며, 측정하지 않은 칸은 비워 둔다. 표 위에 측정
  출처를 표시한다. 방향 버튼은 선택한 결과를 바꾸지 않는다.
- 숫자 셀의 도움말에는 실제 출처의 실행 ID와 기록된 평가 조건을 표시한다.
  평가 조건 필터는 보완하는 결과에도 동일하게 적용하며, 조건 미기록 결과는
  특정 조건을 선택했을 때 제외한다.
- 품질 표는 높이를 제한하고 모델명·언어쌍 머리글을 고정해 스크롤 중에도 읽을 수 있다.
  표는 전체 문서 기준이며, 차트 위의 문서 유형 선택기는 차트·추천·품질 진단에 적용된다.
- 모델 계열: GPT 파랑, Claude 보라, 중국 개발사 모델 주황, 그 외 미국 개발사 모델 청록,
  한국·유럽·알 수 없는 모델 회색. 색상과 텍스트 이름표를 함께 제공한다.
  개발사 분류이며 호스팅 리전이나 데이터 처리 위치의 표시가 아니다.
- 번역 후보는 서로 다른 번역 지시 그룹 안에서 각각 선정한다. 원래 조건 그룹을
  합쳐 단일 우승 모델로 표시하지 않는다. 관측 품질4/5 이상이며 수집·채점이 완비된
  모델에서 품질 높은 순, 비용 낮은 순, 한 건 응답 시간 짧은 순으로 각각 후보를 고른다.
- 금융 QA 후보는 감사된 평가 보고서에서만 표시한다. 전체 응답이 있는 모델 중
  표본 정답률90% 이상에서 세 기준으로 선정한다. 정답률 동률의 품질 우선 후보는
  비용 낮은 순으로2개까지 표시한다.20문항과 한 문항5%p의 한계를 화면에 명시한다.
- 비교표의 활용 방식은 같은 품질 기준과 중앙 응답 시간2초를 기준으로 한 검토 가이드다.
  적합성 보증·SLA가 아니며, 원문·결과물과 자사 문서로 확인하도록 안내한다.
- 비용은 가능하면 저장된 측정 총액/반환 건수(QA는 전체 질문 수)에서 단가를 구해
  입력 건수로 비례 환산한다. 총액이 없을 때만 보고서의 단가를 사용한다.
  문장·문서 조각 기준이며 완성 문서 견적, 운영·검색·검수 비용을 의미하지 않는다.
  누락된 비용은0으로 대체하지 않고 소액도0달러로 반올림해 표시하지 않는다.
- 시간은 전체 실측의 한 건 응답 중앙값이다. 문서 유형을 바꾸어도 시간·비용을
  해당 부분집합의 별도 실측처럼 표시하지 않는다. 총 처리 시간이나 첫 토큰 지연을 추정하지 않는다.
- 모델 추천 링크를 누르면 해당 모델의 실제 결과를 비교할 수 있다. 금융 QA에서는
  틀린 답변도 그대로 보여준다. 검증된 답변 비교는 감사된 QA에 한정하며,
  과거 기준의 정답·단위는 확정된 원문 정답으로 표시하지 않고 원본 보고서로 안내한다.
  추천 링크와 수동 선택 모두 두 모델을 서로 다르게 유지한다(한 모델뿐인 결과는 예외).

## 검증

```sh
node validation/customer-view/selfcheck.cjs
node --check docs/customer.js
node --check docs/app.js
node --check docs/finqa.js
# 별도로 localhost:8782에서 docs/ 정적 서버 실행
PLAYWRIGHT_MODULE=/path/to/playwright CHROMIUM_PATH=/path/to/chromium \
  node validation/customer-view/browser.cjs
# 번역 방향 전환 및 첫 화면 도표 회귀 검사 (현재 게시된 번역 데이터 사용)
PLAYWRIGHT_MODULE=/path/to/playwright CHROMIUM_PATH=/path/to/chromium \
  node validation/customer-view/translation-directions.cjs
# 배포 이후 같은 검사를 공개 URL에서 실행
BENCHMARK_SITE=https://inferplane.github.io/llm-benchmark/ \
  PLAYWRIGHT_MODULE=/path/to/playwright CHROMIUM_PATH=/path/to/chromium \
  node validation/customer-view/translation-directions.cjs
```

실제 결과 데이터로 분류, 그룹별 후보, 임계값, 불완전 측정 제외, 비용 결측·소액과
처리량 환산을 검사한다. 브라우저에서는 두 페이지의 모델 수, 색상 이름표,
비용 입력, 실제 답변 전환, 틀린 답변 보존, 접힌 차트 크기 복원,
모바일·다크 모드 및 모든 과거 QA 결과 선택을 검증한다. 유료 API 호출은 없다.

`translation-directions.cjs`는 네 방향 반복 전환, 방향 변경 시 결과 선택기 유지,
원본 결과와 셀 점수·출처 일치, 보완 결과까지 적용되는 평가 조건 필터와 조건 미기록
결과 제외, 차트 표시, 390/320px 화면과 고정 머리글, EN↔KO 단일 열,
결과가 없는 방향에서의 복구를 검사한다.
