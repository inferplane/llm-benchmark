# GPT-6 Luna 번역·금융 QA 추가 측정

2026-09-25 실측. 기존 GPT-5.6 Luna와 별개인 `openai.gpt-6-luna`를
Bedrock Mantle의 `us-east-1` Responses API로 호출한다.
기존 EC2 역할의 SigV4 임시 자격 증명을 사용하며 별도 API 키나 GPU는 사용하지 않는다.

## 모델·가격 사전 확인

AWS 가격 페이지에 GPT-6 Luna가 등재된 것을 확인했다. 개별 모델 카드와
AWS Price List의 `model` 속성에는 당시 정보가 아직 없었다.
OpenAI 공식 Bedrock 가이드의 모델 ID·리전 설명과 실제 HTTP 200 응답으로
지원 여부를 확인했다. `temperature=0`은 HTTP 400으로 거부됐고,
생략하면 정상 응답했다. 실제 응답의 기본 추론 수준은 `medium`이다.
`preflight.json`에 오류·성공·캐시 계수 사전 확인 결과를 보존했다.

`pricing.json`에 공식 가격 및 Bedrock 가이드의 URL·조회 시점·본문 해시와
계산 근거를 기록했다. 상용 지역 처리 표준 단가로 일반 표준 단가에 10%를
가산했다. 100만 토큰당 일반 입력 $0.11, 출력 $0.55,
캐시 읽기 $0.011, 캐시 쓰기 $0.1375이다. 단가의 실행 설정 원본은
`config.toml`이며 이 파일은 검증 근거다. 실제 청구서와 대조한 금액은 아니다.
기존 모델의 과거 단가를 현재 단가로 바꾸지 않는다.

실제 반복 호출에서 입력 총량2432 중 첫 요청은 캐시 쓰기2430,
다음 요청은 캐시 읽기2430이었다. 따라서 일반 입력은 각2토큰이다.
`bench.run.luna_usage`는 입력 총량에서 캐시 부분집합을 빼고,
모든 성공 응답에 입력 총량과 분리된 과금 계수를 함께 보존한다.
기존 모델과 번역 평가자의 토큰 처리 경로는 바꾸지 않았다.

## 고정 조건과 결과

`contract.json`은 본 실측 전에 고정했다. 번역3300개(30개 방향,
FLORES3000·합성 금융 문서300), 금융 QA20문항을 기존 보존 데이터와
동일하게 사용한다. 번역은 기존 Grok·Kimi와 같은 명시적 번역 지시이며,
이전27개 모델의 원래 프롬프트와 다르다는 구분을 유지한다.
출력 상한4096, 모델 기본 추론medium, temperature 생략,
동시성은 번역8·금융 QA2다.

수집은 시나리오마다 전체 입력을 한 번만 요청한다. 빈 응답·잘림·실패를
없애기 위한 재생성이나 출력 상한 변경을 허용하지 않는다.
종료되지 않은 Responses 응답은 부분 텍스트가 있어도 기존 수집기 규칙대로
실패로 남긴다. 정상 반환된 번역만 기존 두 평가자와 평가 기준으로 채점한다.
번역 품질 평균은 채점 가능한 출력 기준이며 모든 요청의 성공률과 구분한다.
성공 응답의 비용 추정치에는 실패 호출·사전 확인·평가자 비용이 포함되지 않는다.

번역은 **3300/3300개 반환·채점 완료**, 수집 실패·채점 실패·잘림 모두0건이다.
평균 평가 점수는 **4.887/5**, 합성 금융 문서 구간은 **4.815/5**다.
30개 방향 각각110개이며, 추론 비용은 정확한 토큰 합산 기준
$0.512415585(보고서 반올림 $0.5124), 반환 성공 문장당 표시 비용은 $0.00016이다.

금융 QA는 **18/20(90%)**, 정규화 전 정답도18개다.
모든20개가 계산식·선언 단위·요청 단위 검사에 통과했다.
요청 실패·잘림·형식 정규화는0건이다.
원래 채점기를 호출하지 않는 별도 Fraction 계산으로20개 판정을 대조했다.
추론 비용은 $0.0062249(보고서 반올림 $0.0062), 문항당 표시 비용은 $0.00031이다.
오답은 다음 두 건이다.

- `ETR/2002/page_86.pdf-1`: 질문의2005→2004 방향을 반대로 해석했다.
  정답은 `(925005−540372)/540372`, 모델은 `(540372−925005)/925005`이다.
- `AES/2003/page_52.pdf-1`: 3월 말까지의3개월을3월만으로 해석했다.
  정답은1월495+59와3월30+29를 합한613백만 달러인데 모델은59를 답했다.

비교 결과에는 기존 번역30개·금융 QA29개 모델의 점수·비용·샘플을
그대로 보존하고 GPT-6 Luna만 추가한다. 최종 비교 규모는 번역31개,
금융 QA30개 모델이다. 과거28개 금융 QA 모델의560개 판정도 변경 없는
채점기로 재현한다. 이20문항 결과를 공식 FinQA 전체 성능으로 표현하지 않는다.

## 실행·재현

```bash
uv run python -m bench.report --selfcheck
uv run python validation/gpt-6-luna/workflow_selfcheck.py

# 이미 완료된 실제 수집은 다시 호출하지 않는다.
# 아래 명령은 사용했던 실행 경로의 기록이다.
uv run python -m bench.luna_benchmark freeze
uv run python -m bench.luna_benchmark run-qa
uv run python -m bench.luna_benchmark run-translation
uv run python -m bench.luna_benchmark judge
# 채점141개가 저장된 시점에서 위 실행을 종료한 뒤, 완료 판정은 재사용하며
# 동일 평가자의 스케줄링 동시성만8→32로 늘려 나머지를 채점했다.
uv run python validation/gpt-6-luna/judge_continue.py

# 보존된 원본에서 결과 파일 재생성 및 검증
uv run python validation/gpt-6-luna/finalize.py qa
uv run python validation/gpt-6-luna/finalize.py translation
uv run python validation/gpt-6-luna/finalize.py verify
```

사전 고정된 수집·보고 헬퍼는 유지한다. `finalize.py`는 금융 QA 모델의
표시용 제공자 이름을 실제 설정의 `bedrock_mantle`로 지정한다.
이 표시 보정은 요청·점수·단가를 변경하지 않으며 보고서에 보정 파일 해시를 남긴다.
모의 검증은3300개 번역·20개 QA의 실제 파이프라인에 가상 API 응답만 주입해
실패·잘림·캐시 비용·기존 결과 보존·모델 설정 변조·오래된 채점 연결 차단을 확인한다.
실제 결과 검증은 JSON 재생성 일치, 독립 Decimal 비용 합산,
독립 Fraction QA 연산을 검사하고 `final-verification.json`에 기록한다.

모델 응답의 수집 동시성·측정 시간·추론 설정은 바꾸지 않았다.
채점 스케줄링 변경은 `judge-scheduling.json`에 별도 기록한다.
이미 완료한141개 판정은 재사용한다. 중단 때 저장되지 않은 평가자 호출은
다시 요청됐을 수 있으며 그 추가 청구액은 채점 비용 추정치에 포함되지 않는다.
채점 비용 표시는 기존 평가자 설정 단가 기준 $67.3751이며,
현재 청구서와 대조한 실제 총지출이 아니다. 후보 모델의 추론 비용과 별도다.

최종 검증에서 결과 JSON 재생성 일치, 기존 모델·샘플 보존,
독립 비용 합산과 QA 계산 검사가 모두 통과했다. 로컬 브라우저에서는
번역31개·금융 QA30개 모델, 명시적 지시4개·기존 지시27개 구분,
점수·비용·실패 표시, 과거 결과 선택, 모바일 화면과 상세 보고서 연결을 확인했다.
