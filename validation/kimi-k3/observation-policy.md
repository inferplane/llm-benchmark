# 최초 번역 결과의 실패·잘림 보존

Kimi 수집 중 일부 긴 문장에서 빈 최종 출력과 `max_tokens` 종료가 관측됐다.
기존 추가 보고서의 “모든 입력에 정상 출력이 있어야 통합” 조건은 이런 실제
모델 결과를 표시할 수 없었다. 이 때문에 결과를 재생성해 정상 출력만 선택하는
대신, 별도 관측 보고서를 만든다.

**수집기, 요청, 토큰 상한4096, 데이터, 프롬프트, 평가자·루브릭, 기존 모델
결과는 바꾸지 않는다.** 입력3300개마다 최초 저장된 결과를 그대로 유지한다.
빈 출력은 번역 실패로 남기고, 잘린 출력은 종료 플래그로 별도 집계한다.
반환된 텍스트가 있는 경우에는 원래 두 평가자가 원래 루브릭으로 평가한다.
실패 입력에 가짜 점수를 채우거나 평가 가능한 출력만 전체 모집단인 것처럼
표시하지 않는다. 검토 건수/전체 입력 수와 미반환·상한 도달 수를 함께 공개한다.

`bench/kimi_observed.py`는 고정된 수집 계약과 모든3300개 원본을 확인한다.
이 **보고 방식은 수집 결과를 본 뒤, 번역 채점 전에 기록**한다. 원래부터
사전 등록돼 있었다고 주장하지 않는다. `observation-policy.json`에 시점,
원본 해시, 기존 평가 코드·루브릭, 별도 보고 코드 해시를 남긴다.

```bash
uv run python -m bench.kimi_observed policy
uv run python -m bench.kimi_observed judge
uv run python -m bench.kimi_observed report
uv run python validation/kimi-k3/final_check.py
```

표준 품질 통계는 평가 가능한 반환 텍스트에 대한 조건부 값이다.
비용도 정상적으로 텍스트가 반환된 결과의 추정치이며, 실패 호출의 캐시 사용량은
완전히 보존되지 않아 전체 시도 청구액을 계산했다고 주장하지 않는다.
금융 QA는 별도20문항에서 정상 완료됐으므로 원래의 추가 측정 보고서를 사용한다.
